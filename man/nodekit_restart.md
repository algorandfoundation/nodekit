## nodekit restart

Restart the node daemon

### Synopsis

                                                                                                                        
<img alt="Terminal Render" src="/assets/nodekit.png" width="65%">                                                                 
                                                                                                                        
                                                                                                                        
Restart the node daemon                                                                                                 
                                                                                                                        
Overview:                                                                                                               
Stops the Algorand daemon on your local machine and starts it again. Optionally, the daemon can be forcefully restarted.
                                                                                                                        
This requires the daemon to be installed and running on your system.                                                    

```
nodekit restart [flags]
```

### Options

```
  -d, --datadir string   Data directory for the node
  -f, --force            forcefully restart the node
  -h, --help             help for restart
```
